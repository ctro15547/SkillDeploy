# 提交信息格式规范

## 标准格式

```
类型(范围): 简要描述

变更说明1

变更说明2

[日期] YYYYMMDD
```

- 第一行：类型 + 范围（可选）+ 冒号 + 空格 + 简要描述（不超过50字）
- 空一行后写详细变更说明，每条说明单独一行
- 末尾加 `[日期] YYYYMMDD`

## 范文示例

```
feat(auto_pair): 添加5分钟全局超时机制

添加全局超时变量 SCRIPT_START_TIME 和 GLOBAL_TIMEOUT

脚本启动即开始计时，覆盖整个流程

ask_to_continue支持30秒超时并显示剩余总时间

配对模式使用全局计时器检查超时

[日期] 20250209
```

```
fix(login): 修复用户登录后跳转失败的问题

修复 redirect_url 参数未正确传递的 bug

增加登录成功后的日志输出

[日期] 20250301
```

```
docs(readme): 更新安装说明和环境要求

补充 Python 3.10+ 版本要求

添加 macOS 和 Windows 的安装步骤差异说明

[日期] 20250215
```

## 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 暂存区为空 | 自动执行 `git add .`，再次检查 |
| `git add` 后仍为空 | 提示用户无可提交变更，终止流程 |
| push 失败（需要 pull） | 提示用户先执行 `git pull --rebase`，再重试 |
| 用户拒绝提交信息 | 询问修改意见，重新生成后再次确认 |
| 多个模块同时变更 | 选择变更最多的模块作为范围，或使用 `*` |
